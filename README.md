# Portfolio Poetry Collection

A personal portfolio website built for **Diya Subedi**, combining poetry and web development into a single reading experience.

Instead of treating poems as social media posts, this project presents them as a searchable digital collection with dedicated reading pages, video performances, responsive layouts, and a clean editorial design.

## How Poems Work

The website loads poem information from:

```
data/poems.json
```

Each poem contains information such as:

* title
* subtitle
* slug
* category
* thumbnail
* video
* publication date
* quote
* meaning
* author notes

When a visitor opens a poem, the page is generated dynamically using JavaScript.
